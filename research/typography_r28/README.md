## 2. 纠正历史上两个方向性错误

**不是“永远禁止字库”。** 原作者先在屏幕一侧放字库文字校对结构。合法字体作为**文字骨架参考**是设计过程正常一步，但把字库轮廓直接转成SVG，再叫原创字体是不诚实的。

**不是“自己画的曲线就有设计感”。** R25有原生Figma可编辑向量、R26有跨字共笔、R27有26条自写轮廓，但依然未形成专业视觉身份。原作者是先按字组整体重新核对高低、疏密、字重，然后再选用母题与特征笔；我们此前反过来执行，所以大量失败。
