## 已实际解决的问题

上一份仅含一张PNG和两段说明的匿名评审包，虽然未揭晓甲乙映射，却把两阶段问题放在同一个Markdown文件中，评审者可以提前看到“茶馆”行业背景，不能可靠地分离无提示识字与品牌喜好。此次使用以前冻结的匿名PNG，制作了完全离线、无网络上报的双阶段HTML：
- 第一阶段：按真实所见分别填两版中文字、哪版更易读、疑似含糊笔画、此前是否见过作品及设备；输入必填，提交后当次会话无法再更改。
- 第二阶段：只有锁定第一阶段答案后，页面才显示“虚构的当代中文茶馆”定位与品牌适配、独立识别性、节奏及理由。可选择“差不多/都不行/无法判断”，不预设B必胜。
- 导出：生成包含完整原始答卷、ISO时刻、匿名随机会话号、第一阶段UTF-8 JSON摘要SHA256的答卷。纯前端，离线使用，无用户数据发送服务器。用户可下载JSON或选中文本复制。
- 手机：原图左右两方案在手机缩得太小，故只从匿名原图作同尺寸等比例像素裁切展示两套放大图，不改笔画与匿名顺序。原对照图SHA256保持`a5e545f01624c063767a3917a44e5724aa947c582582827303302c0957797977`。
