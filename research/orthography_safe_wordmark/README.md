# 新专项｜“金尊”20条来源笔画约束下的真实造型实验

**日期：2026-10-28；结果：来源追踪及SVG几何技术通过，但创意预审失败。**

这不是R30，不假定“金尊”是用户已批准的正式品牌文字。它只是对应任务主题的一组新测试文字，目的是把用户最新强调的「中文字形不能乱加笔画」变成真正能阻断错误的执行关卡。

## 真实出图

以[金（教育部标准8画）](https://stroke-order.learningweb.moe.edu.tw/dictMean.jsp?ID=37329&la=0)、[尊（教育部12画）](https://dict.revised.moe.edu.tw/dictView.jsp?ID=9670&la=0&powerMode=0)为笔画数参照，使用固定源码 `chanind/hanzi-writer-data@68d10a4...` 中的数据中线，各按8/12条源语义笔画绘制一对笔画，不使用字体字形轮廓作为B版设计替身，亦不额外添加自说自话的装饰笔画。字库Noto Sans仅展示标准认读参考。

A为均衡笔触重建；B在同样20条笔画的基础上改变原有压笔和少量起收笔曲率。两份均为1880×800透明PNG，并有真正可单独编辑的20条SVG轮廓。

## 错误与技术回执

最初渲染算法在复杂钩笔处让左/右偏移轮廓相交，A/B**各有8个非法SVG闭合多边形**。第一次错误保留在交付源码 `build_trial.py` 与失败回执；纠正为连续可变笔幅笔尖区域的布尔并集，依旧仅原20笔，无增笔、没有第二次艺术性择优。

复算：A/B各20条几何有效闭合曲线路径，语义ID分别对应金8／尊12；SVG重新栅格化PNG原字节一致。A/B像素不同24450个，二值墨区IoU约0.84188；**数字仅说明形态有变化，绝不表示设计提高**。

两张作品大图及96／64像素真实对照后，B并没有建立明显新造型语言，仍然细弱、缺乏字组重量协调、像练习字；甚至弱于标准字体认读参考。**创意预审FAIL，不进Figma、不启动新编号继续微调。**

还要注意：Hanzi Writer数据来自Arphic字体的教育用笔顺中线，来源数量对并不意味最终完整字形规范正确。用户没有审本次完整字形，中文人读字门未通过正式验收。这里不把任何方案认定为标准书法／成熟商业字标。

## 核心纠正

**汉字没有多写一笔，也仍然可能画得不好甚至不易辨认。** 笔画数只是一道来源门，不能代替完整字形检查，更不能产生高级美感。

下一步应停止「先把中线描成自己的轮廓」的技术死循环。用真实设计师的整字前后修订证据寻找一项可见的造型判断，并先通过中文读字及整组审美门；若没有真正优于字库基线的方案，暂不做Figma交付。
