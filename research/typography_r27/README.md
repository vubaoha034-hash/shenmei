## 一、权威参考与来源边界

- 设计师：梁志坚，《海棠未雨》，发表于[优设《实战案例！详细剖析11款字体的设计全过程（上篇）》](https://www.uisdc.com/11-font-design-case)（2019-03-31）。
- 可核实的作者描述：先确定古典、唯美气质，在“海浪”与“古建筑屋檐”两个视觉母题中选后者；将抽象屋檐自然融进各字原生笔画。与其相邻的特征笔要错开，不应排成相同高度；单字识别和整组视觉重量必须同时成立。
- 本次只从作者已发表的工艺描述抽取**候选创作决策**。没有获取、临摹、改写、重发作者原始的轮廓控制点或图片。源图阶段的文字说明已经复核，非作者的主观满意度指标不是我们的验收结果。

## 二、研究对象与技术来源

测试词：**亭下听风**。不与《海棠未雨》复用任何完整字组。

- **A（识字基线）**：系统安装的 Noto Serif CJK SC 字库，仅本机渲染比较。字库源文件不复制、不随包分发。这一臂本就不是原创设计。
- **B（独立造型试验）**：26条人工编写的填色贝塞尔曲线路径，每个路径含字和结构笔画语义名，来自空白坐标，不取字体轮廓、不从生成图或第三方参考自动描摹。
- 可见设计动作：复杂的“亭”保留点、口、冖和丁；疏朗的“下”保留一横一竖一点；“听”完整保留口和斤的关系；“风”保留外框与两道内笔。屋檐特征只分配给“亭”的主题屋檐横和“风”的外框顶横，且两者在不同高度，并不四字重复。

## 三、实际失效与独立审核

1. **第一次原始 SVG 工程失效**：`风/内捺` 的一个 `C` 指令缺少一组控制数值，渲染产生巨大黑三角。保留在 `audit/R27_B_FIRST_FAILED_invalid_cubic.{svg,png}`；仅修补指令语法，不把工程修复当审美提升。
2. 修复后从真实源 SVG 经 CairoSVG 渲染得到透明 PNG：26个语义路径都存在，语法检查和逐路径边界审计无错误。
3. **审美/字组结构失败**：人工原创B在等墨高对照里明显不如A统一，风字宽467px、亭字宽330px、下字252px，风的实际墨迹面积约46,150像素、下约18,944像素；视觉重量未充分均衡。“听”的口与斤更像分列单体，“亭”的点与屋檐也缺乏应有整合感，母题特征并未建立新的识别性字族。
4. 96px和64px缩略图已经导出，但这仅供实际视觉审核，**没有招募陌生人进行不知文字内容的盲测**。程序不能宣称认读性必然通过，AI自我判断不能当真人满意度。
5. B在1800×620画幅的原生墨迹高度486px，A仅232px；不能用未经缩放的大图直接宣称B更“有存在感”。本包额外交付统一墨高230px的等尺度对照，原件保持不变。

## 四、一次失败真正学到的内容

- `机理可执行` ≠ `机理有效`：即使照作者描述给两个字不同高度的“屋檐”特征，若四字的外轮廓、墨量和视觉重点缺少协调，最后依然不像专业品牌字体。
- 本次失败进一步证明，**先做视觉与识字审查，拒绝再进Figma**比「每个候选先矢量写进Figma再打回」更符合项目目标。
- 下一轮不能继续迭代这版“亭下听风”笔画参数。应对一组作者真实初稿、中间稿和定稿建立具体的整组视觉变化说明，并先确保**构图和轮廓发生视觉上有价值的改变**，才开始另一个文本的原生设计。
- 任何需要的光学均衡阈值都是我们自己提出的测试启发式，不能冒称梁志坚本人规定；严禁用阈值替代专业审美验收。
