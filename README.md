# shenmei｜餐饮品牌、海报、经营与私人审美系统

本仓库现包含四个独立但可组合的系统：

1. 国内餐饮品牌案例与十图概念；
2. 餐饮海报生成和发布级审核；
3. 私人审美评分和校准；
4. **Restaurant Operations Master**：单店经济、菜单、产能、供应/食安、门店试点和多店复制。
