# VPD V2 Next Experiment

## Experiment

`A2_FORCED_RED_CONTROL_ABLATION`

Type: `PROMPT_COMPILER_ABLATION`

This is exactly one experiment. It is not authorized for execution by the current diagnosis task.

## Hypothesis

The Style A content-swap failure was materially caused by one interfering payload control: forcing the egg/yolk/sauce colors into a deep fermented-red structural zone. For this static plated source, that binding promotes a content-specific heat cue into a compulsory style device and pushes the renderer toward the generic black/red/brush restaurant-poster treatment identified in the frozen review.

Removing only that control, without adding a replacement, should improve graphic-design quality and photo/design integration while preserving the verified food and material realism.

## Changed variable

For the ablated V2 condition only, remove the single A2 renderer-payload control that requires the dish's warm yolk/red sauce to become a deep fermented-chili-red structural zone.

Do not change the capsule, compiler code, architecture, causal evidence, or any other renderer control.

## Frozen variables

- Same raw Style A reference bytes and same genuinely different content-swap source bytes, verified by their locked private hashes.
- Same `4:5 portrait` target and same exact headline.
- Same strongest available visual model and renderer tool for all three conditions in one run.
- Same current A2 payload for the current-V2 control; the ablated condition retains the other seven controls and all six hard avoids verbatim.
- Same one-attempt policy, except replacement after invalid image bytes; invalid artifacts are quarantined and never reviewed.
- Same blind randomization, human rubric, and freeze-before-unblind procedure.
- No manual Figma lettering, no extra references, no aesthetic-rule addition, no Discovery change, and no Scale Gate.

## Baseline and conditions

1. `E0_MATCHED_DIRECT`: raw Style A reference plus the A2 content source and the same short DIRECT instruction; zero V2 controls.
2. `E1_CURRENT_V2`: the current locked A2 payload, unchanged.
3. `E2_V2_NO_FORCED_RED_ZONE`: identical to E1 except for the one removed control.

## Exact output count

Exactly `3` valid primary outputs: one per condition. No best-of-N, cosmetic retry, or additional variant.

## Pass/fail rule

Freeze an independent blind review before mapping disclosure.

The hypothesis passes only if `E2_V2_NO_FORCED_RED_ZONE`:

- is judged `USABLE`;
- scores at least `+2` over `E1_CURRENT_V2` in both graphic design and integration;
- is not below `E0_MATCHED_DIRECT` in either graphic design or integration;
- retains photography at `>= 7` and material realism at `>= 7`; and
- is not tagged by the reviewer as a generic black/red/brush restaurant-poster treatment.

Any unmet condition is a fail. Do not reinterpret a realism-only gain as a pass.

## Stop rule

After three valid outputs are blind-reviewed, frozen, and unblinded, stop. If the pass rule succeeds, a later task may propose replication; if it fails, reject the forced-red-control hypothesis and do not generate follow-up variants. In either case, do not enter Library Scale Gate.
