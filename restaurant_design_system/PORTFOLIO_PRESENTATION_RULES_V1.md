# 国内餐饮品牌作品集式呈现规则 V2.0

版本：`2.0.0`
状态：`MANDATORY`
适用阶段：`THREE_PAGE_PROOF`、`CONCEPT_SET`、`DESIGN_DEVELOPMENT`、`READY_TO_POST_SET`

## 1. 核心定义

正确交付不是十张孤立广告，也不是一张大拼贴，而是：

> 十张由 Figma 真实排版的独立品牌提案页面，共同组成一套连续品牌案例。每页只讲一个章节，但可以在该章节内呈现主视觉、设计细节和相关应用证明。

图像模型生成的完整页面、三联页、九宫格和总拼贴均不属于正式作品集页面。

## 2. 三页先行

完整十页前必须先完成三页 Figma 验证：

1. 品牌概念与主视觉；
2. 店名字标、Logo 和超级符号；
3. 最强应用触点。

三页未通过 `restaurant-brand-aesthetic-gate` 时，禁止扩展十页。

## 3. Figma 真实排版要求

每个正式页面必须：

- 是独立 Figma Frame；
- 有真实 file URL 和 node ID；
- 页码、章节名、品牌名、主文案和状态为真实可编辑文字；
- 使用同一颜色、字体、间距和组件系统；
- 图片作为素材被放置和裁切，而不是导入一张 AI 完整页面；
- 记录实际 Frame 尺寸和导出尺寸。

无 Figma 文件 URL、node ID 或真实文字，页面不得进入 `CONCEPT_SET`。

## 4. 十页固定章节

### 01 品牌概念与主视觉

建立品牌存在理由、具体主张和第一印象。应像作品集开篇，不是促销广告。

### 02 店名海报 / Logo / 字标 / 超级符号

展示中文主识别、字标逻辑、图形标、横竖组合和关键构造。

### 03 视觉 DNA

展示色彩、字体、材质、纹理、图形、插画和摄影规则。

### 04 招牌产品与产品视觉系统

展示招牌产品、产品局部、结构和摄影规则。AI 产品素材必须标注概念属性。

### 05 快餐打包盒与包装系统

以核心盒型为主，关联纸袋、筷套、小料袋、杯子或餐巾纸。不得伪装成真实刀版。

### 06 品牌主题海报与墙面海报系列

展示 2–3 张主题一致、构图不同的海报，并证明其门店应用。

### 07 食材 / 工艺 / 地域 / 品牌故事

选择一条真正支撑品牌发动机的叙事。不得堆砌旅游景观和泛地域符号。

### 08 门头与空间应用

证明平面系统如何进入门头、入口、墙面、点餐区和品牌装置。无实测尺寸时标注概念。

### 09 菜单、员工服与运营触点

选择 2–4 个真实经营触点。未确认价格和菜单时必须标注示意。

### 10 品牌视觉总览与收尾

总结策略、字标、色彩、母题、摄影、材料和代表应用。不得替代前九页。

## 5. 统一页面系统

必须在 Figma 建立：

- 安全边距；
- 页码与章节组件；
- 品牌签名和状态组件；
- 标题、正文、注释和数字文字样式；
- 主色、强调色、中性色和背景变量；
- 间距和线条规则；
- 图片容器和裁切规则；
- 导出设置。

建议：

- 安全边距为画布宽度 5%–7%；
- 页眉或页脚为画布高度 4%–7%；
- 主视觉信息权重 55%–75%；
- 细节和应用 15%–35%；
- 说明文字 5%–15%。

## 6. 版式变化

统一不等于同版式。

十页至少使用 4 种原型：

- 全幅主视觉；
- 上下双模块；
- 左右分栏；
- 主图加局部；
- 三联系列；
- 场景加拆解；
- 系统矩阵；
- 空间大图加应用。

同一原型不得连续超过 2 页。禁止十页全部采用“顶部标题 + 中间大图 + 底部三个图标”。

## 7. 每页信息逻辑

每页必须有：

1. 一个核心结论；
2. 一个主视觉或主应用；
3. 必要的设计细节；
4. 与章节直接相关的应用证明；
5. 一条有效 `brand_evidence`。

不得通过堆满文字制造专业感。

## 8. 品牌证据

每页记录：

`brand_evidence: 除 Logo 和颜色外，本页通过什么证明只属于这个品牌。`

有效证据包括：

- 专属经营规则；
- 品牌观点；
- 独有图形机制；
- 产品结构；
- 包装开启方式；
- 服务动作；
- 空间装置；
- 摄影和材料规则；
- 品牌故事。

只有 Logo、颜色或通用菜品图，页面直接 `REJECTED`。

## 9. 图像素材边界

image_gen 只提供无文字素材。

禁止素材包含：

- 品牌名和 Logo；
- 菜单和价格；
- 页码和章节；
- 二维码、电话、地址；
- 完整海报排版；
- 作品集页脚和说明。

含关键伪文字的素材不得进入 Figma。

## 10. 参考图边界

允许学习：

- 章节结构；
- 页面节奏；
- 主图、细节和应用比例；
- 留白和裁切；
- 平面、包装、空间和摄影的统一方法。

禁止复制：

- 品牌名、Logo、口号、字体造型；
- 具体页面构图；
- 包装外观；
- 设计公司署名、水印、二维码、电话、地址和页脚；
- 绿色、米白、山野、云南等表面组合；
- 虚构日期和无意义英文。

## 11. 强制审计

### 单页

- 是否是独立 Figma Frame；
- 是否只讲一个章节；
- 是否有一个明确结论；
- 是否有主图和必要证据；
- 是否使用真实文字；
- 是否存在伪文字、结构错误或通用 Mockup；
- brand_evidence 是否有效。

### 整套

- 是否像同一本品牌画册；
- 是否共享变量与组件；
- 是否至少四种版式；
- 是否没有连续模板复制；
- 是否形成连续叙事；
- 是否十个 node ID 和十个独立导出齐全；
- 是否未使用 AI 完整页面。

任一硬门槛失败，不得标记 `CONCEPT_SET`。

## 12. 状态

- `THREE_PAGE_PROOF`：三页已排版，待评估；
- `THREE_PAGE_PROOF_PASS`：可以扩展十页；
- `THREE_PAGE_PROOF_REJECTED`：禁止扩展；
- `TEN_PAGE_LAYOUT`：十页 Figma 排版中；
- `CONCEPT_SET`：十页、导出和全部审计通过；
- `BLOCKED_FIGMA_ACCESS`：无法完成真实排版；
- `REJECTED_AI_FULL_PAGE`：错误使用图像模型直接生成页面。
