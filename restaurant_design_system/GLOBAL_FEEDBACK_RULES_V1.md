# 国内餐饮品牌项目全局反馈规则 V1.0

版本：`1.0.0`
状态：`MANDATORY`

## 1. 已明确认可的长期方向

- 方案必须有真实品牌策略，不是十张独立好看图；
- 海报、墙面海报、店名海报、主题海报、门头、快餐打包盒、纸袋与餐具包装、菜单和品牌总览是核心触点；
- 十张图必须成为同一品牌的十个证据；
- 参考优秀案例时学习品牌故事、视觉语法、材料和空间统一方法，不复制表面风格；
- 执行者应主动提出方向、判断风险和改进设计，不应长期等待用户逐项纠错；
- 国内餐饮语境可以使用现代、编辑、工业、地域、生活方式等多种设计语言；
- 生成素材必须尽量去除 AI 味，正式文字和排版应由真实字体、Figma、Adobe 或矢量工具完成。

## 2. 反重复长期规则

> 同一个样式只能偶尔作为一种方向出现，绝不能连续、频繁、习惯性延续。新方案必须像新方案，而不是旧模板的改名版。

以下组合不得连续或高频出现：

- 米白 + 橄榄绿 + 木色 + 社区治愈小馆；
- 米白 + 书法 / 红章 + 轻东方；
- 黑红 + 不锈钢 + 霓虹 + 火焰工业锅气；
- 只换店名和菜品、但版式、空间、包装和门头完全相同的模板；
- 通用“标题 + 大菜品 + 三个卖点图标 + 底部信息栏”版式。

这些方向并非永久禁止，但只能在长期项目中低频、间隔使用，并且必须有新的品牌策略和视觉 DNA。

## 3. 已明确不喜欢的方向

### 强烈不喜欢 / 默认禁止

- 黑红金属工业风、红色霓虹、满版火焰、强烈不锈钢质感的“锅气小炒”模板；
- 脏黑、过度攻击、廉价夜店或电竞风；
- 同一工业样式在海报、门头、菜单、包装和导视上机械重复；
- 以大字、红黑和火焰堆砌代替品牌策略。

除非用户明确重新要求，不得主动再次使用该方向。

### 条件性不喜欢

- 米白、绿色、木色、温暖自然光的社区治愈风，在连续重复时判定为不喜欢；
- 轻 IP / 动物角色若只是可爱装饰、缺乏品牌故事或压过产品，判定为不合格；
- 大量做旧纸张、木刻动物、山野叙事若只是复制参考案例表面，判定为不合格。

## 4. 品牌感判定

被认为有品牌感的方案通常具备：

- 一句专属、具体、可验证的品牌主张；
- 一个能延展到多个触点的核心图形母题；
- 字体有明确性格和层级；
- 海报、墙面、门头、包装、菜单和空间使用统一视觉语法；
- 重复品牌资产，但不重复同一版式；
- 材质、尺寸、印刷、灯光和运营逻辑真实；
- 图形与文案来自产品、地域、工艺或经营承诺，而不是纯装饰。

## 5. 新方案前强制读取

每次新方案必须读取本文件，并列出：

- 最近五套使用过的母风格；
- 本次必须避开的两个以上模板；
- 本次至少四项明确变化；
- 为什么本次不是旧模板改名版。
