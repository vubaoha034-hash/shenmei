# 国内餐饮案例方向库 V1.0

版本：`1.0.0`
状态：`MANDATORY`

## 1. 使用边界

本方向库服务于中国餐饮市场的品牌设计案例。它解决两个长期错误：

1. 把“国内餐饮”误解为只能使用传统中式审美；
2. 把“不同风格”误解为直接改做国外餐饮品牌。

正确方式是：保留真实的国内餐饮品类、消费场景和经营逻辑，同时使用多样化、现代化的设计语言。

## 2. 品类库

### A01 中式炒菜 / 家常小炒 / 下饭菜

子类型：

- 家常小炒；
- 现炒快餐；
- 下饭菜馆；
- 小碗菜；
- 自选菜；
- 农家小炒；
- 盖浇饭、木桶饭、铁板饭；
- 社区家常菜馆。

适合人格：国民下饭、社区温暖、烟火高级、都市升级、治愈 IP。

可提取母题：锅气、灶火、现炒动作、米饭、菜单勾选、家常器皿、社区日常。

### A02 原创人格 IP 小馆（“田小狗类型”）

定义：以原创名称、人格、动物或生活角色形成记忆点的小型本土餐饮品牌。重点是亲切、松弛、有故事感，不是幼稚卡通店。

子类型：

- 家常菜小馆；
- 社区炒菜馆；
- 便当小店；
- 早餐小馆；
- 面馆、粉馆；
- 田园或县城生活主题小馆。

硬规则：

- 不复制任何现有品牌名称、角色、口号、字体或商业外观；
- IP 必须原创；
- 角色只做品牌人格辅助，不能压过产品与餐饮属性；
- 可爱不等于儿童化，乡土不等于低级。

适合人格：治愈 IP、社区温暖、田园生活、轻复古、烟火生活。

### A03 地方菜系小馆

子类型：

- 川菜；
- 湘菜；
- 赣菜；
- 云贵菜；
- 东北菜；
- 西北菜；
- 江浙家常菜；
- 潮汕风味；
- 客家菜；
- 民族与地域风味餐饮。

适合人格：地方文化现代化、烟火高级、都市升级、国民下饭。

硬规则：地方文化只能作为真实来源，不得堆砌符号、服饰、方言和旅游景观。

## 3. 选题规则

每个项目必须从本库选择一个主品类，并最多增加一个合理复合品类。禁止为追求丰富把三种以上业态塞进同一品牌。

项目 brief 必须记录：

- `category_id`；
- 主打产品；
- 主要消费时段；
- 目标客群；
- 价格带；
- 门店场景；
- 适合的品牌人格；
- 不适合的风格。

## 4. 连续项目去重

- 连续两天不得使用相同主品类；
- 最近 7 个项目内，同一主品类最多出现 2 次；
- 若重复品类，品牌人格和主视觉风格必须完全不同；
- 不得因生成效果稳定而长期只做烤鱼、烧烤、面馆等少数品类。
