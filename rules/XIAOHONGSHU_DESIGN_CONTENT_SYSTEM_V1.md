# 小红书餐饮设计内容系统 V1

版本：`1.0.0`
状态：`MANDATORY`
适用：餐饮品牌设计案例、菜单设计、门头设计、海报设计、AI 视觉案例、设计拆解与餐饮经营者视角内容。

## 1. 基本判断

小红书餐饮设计内容不能只按“强冲突标题”生产。

对设计赛道，常见的第一驱动力是：

> 这组设计是否值得保存。

收藏和评论是两套不同机制：

- 收藏来自可带走的视觉证据、信息密度和检索价值；
- 评论来自具体、可争论、证据充分的设计判断；
- 客户转化来自真实经营问题、设计取舍与落地结果。

不得把任何单一样本、搜索排序或经验比例冒充小红书官方算法权重。

## 2. 发布前必须声明目标

每篇内容必须声明一个主目标：

```text
COLLECTION  收藏型
DISCUSSION  评论型
CONVERSION  转化型
```

允许一个次目标，但不得三种目标平均混在一篇内容中。

推荐账号内容结构：

```text
收藏型：50%
评论型：30%
转化型：20%
```

这是账号运营分配，不是平台官方权重。

## 3. 收藏型内容

### 核心公式

```text
明确对象 + 可带走内容 + 准确搜索词
```

### 用户保存的理由

至少提供一种明确价值：

- 可以直接参考的结构；
- 可复用的设计方法；
- 尺寸、材料或工艺信息；
- 前后对比；
- 视觉元素分类；
- 菜单层级拆解；
- 门头价格表达方式；
- 完整案例流程；
- 一组高质量风格样本；
- 可用于后续工作的清单。

### 标题规则

标题可以直接、朴素、搜索友好，不强制制造冲突。

推荐结构：

- `8组餐饮菜单信息层级，做快餐店可以直接参考`
- `餐饮门头常用的6种价格表达方式`
- `新中式餐饮品牌，怎样把食材画成记忆符号`
- `一套菜单从封面到点单页，我把结构拆开了`
- `餐饮品牌好看的手绘元素`
- `中式审美排版小元素`

标题必须包含真实内容，不得用数字夸大、不得承诺正文不存在的资料。

### 首图规则

首图需要同时满足：

- 一眼看清设计类别；
- 视觉质量足够高；
- 信息密度让保存有理由；
- 字不压过作品；
- 小尺寸仍能识别主内容；
- 与标题搜索词语义一致。

优先使用：

- 高质量四宫格；
- 菜单局部与整体对照；
- 门头实拍；
- 前后对比；
- 一页完整设计拆解；
- 同一视觉语言下的元素合集。

## 4. 评论型内容

### 核心公式

```text
具体判断 + 两份真实证据 + 窄而明确的选择题
```

### 判断必须具体

有效判断：

- 同样卖一碗面，写字楼店应该先让顾客看到价格，还是招牌产品；
- 门头只保留品牌名，还是同时放核心品类；
- 菜单首页先放套餐，还是先放高毛利招牌菜；
- A 版突出 19.9 元，B 版突出产品，哪版更适合午餐高峰。

无效判断：

- 设计到底重不重要；
- 好看和生意哪个更重要；
- 大家喜欢哪种风格；
- 你觉得怎么样。

### 证据要求

至少提供两项可见证据：

- A/B 两版设计；
- 真实门头；
- 菜单视线顺序；
- 顾客停留位置；
- 点单动作；
- 价格信息；
- 经营场景差异；
- 修改前后结果。

### 结尾问题

问题必须缩窄到可以立即回答。

正确：

> A 版先突出 19.9 元，B 版先突出招牌菜。店开在写字楼楼下，你会用哪版？

错误：

> 大家觉得怎么样？

## 5. 转化型内容

### 核心公式

```text
真实经营问题 + 设计取舍 + 实际落地结果或可验证后果
```

### 最强证据

餐饮经营者与设计师的双重身份，是普通设计账号难以复制的证据。

内容应说明：

- 顾客在什么场景下看到设计；
- 顾客有多少时间理解；
- 哪些信息必须先出现；
- 删除了什么；
- 为什么舍弃设计师喜欢但顾客无感的内容；
- 设计怎样影响看见、理解、选择、点单、记忆或复购。

示例结构：

> 我自己开店以后，删掉了菜单上这三类设计师很喜欢的东西。不是因为不好看，而是顾客站在称菜区时根本来不及看。

### 禁止空转化

以下不能单独作为客户信任证据：

- 标准样机；
- 抽象品牌故事；
- “高级”“年轻”“有温度”等自我评价；
- 没有实物和场景的效果图；
- 没有取舍逻辑的完整案例；
- 只展示 AI 生成能力。

## 6. 首图优先级

默认优先级：

1. 真实落地门头；
2. 真实菜单或点单现场；
3. 前后对比；
4. 产品、材料和印刷细节；
5. 高质量四宫格作品总览；
6. 完整案例页；
7. 标准样机。

标准样机和抽象品牌故事不得长期作为账号主力。

## 7. 文案与设计的关系

文案负责：

- 说明这组设计为什么值得看；
- 提供搜索语义；
- 补充视觉无法表达的取舍；
- 提出一个明确讨论问题；
- 解释真实经营结果。

文案不得：

- 压过设计；
- 把首图变成大字报；
- 用焦虑模板代替证据；
- 用长篇抽象理论掩盖作品普通；
- 用感叹号制造虚假冲突。

## 8. 模板钩子限制

以下标题不是禁用词，但默认视为高风险模板：

- 老板必看；
- 三大避坑；
- 顾客只看三秒；
- 谁说××只能土味；
- 设计师不会告诉你；
- 做餐饮一定要知道。

只有同时满足以下条件才可使用：

1. 视觉证据强；
2. 判断具体；
3. 正文兑现；
4. 不是同类账号常见套话；
5. 标题与搜索对象一致。

否则标记 `REJECTED_GENERIC_HOOK`。

## 9. 搜索语义一致性

标题、正文、首图和话题必须围绕同一明确对象。

例如内容是菜单层级，就不得使用只描述品牌故事的标题；内容是门头价格表达，就不得在正文大篇幅转去谈 AI 生成。

发布记录必须写出：

```text
primary_search_phrase:
secondary_search_phrases:
first_image_category:
content_promise:
where_the_promise_is_delivered:
```

## 10. 灵感合集与客户内容的区别

灵感合集的主要受众可能是：

- 设计师；
- 学生；
- 素材收集者；
- 同行业从业者。

它们适合：

- 增长曝光；
- 增长收藏；
- 建立审美标签；
- 扩大搜索入口。

但餐饮老板的信任主要来自：

- 自有项目；
- 真实经营；
- 商业取舍；
- 落地物料；
- 门店现场；
- 结果与复盘。

不得用大量灵感搬运替代自己的商业证据。

## 11. 内容配比执行

每 10 篇内容建议检查一次：

```text
收藏型目标：5篇
评论型目标：3篇
转化型目标：2篇
```

允许根据阶段调整，但必须说明：

- 当前主要目标；
- 受众结构；
- 是否缺少餐饮老板内容；
- 是否过度吸引设计师而没有客户；
- 是否连续发布同类首图和标题。

## 12. 作品证据等级

### A 级｜真实商业证据

- 落地门店；
- 真实菜单；
- 真实包装；
- 经营数据或明确行为结果；
- 真实前后对比。

### B 级｜完整原创案例

- 自己建立的品牌概念；
- 完整视觉系统；
- 真实产品依据；
- 多触点延展；
- 清楚取舍逻辑。

### C 级｜方法与拆解

- 菜单结构；
- 门头层级；
- 价格表达；
- 材料与尺寸；
- 视觉元素分类。

### D 级｜灵感合集

- 风格参考；
- 素材整理；
- 排版元素；
- 视觉趋势。

转化型内容原则上必须使用 A 或 B 级证据。D 级内容不得伪装成自己的完整商业案例。

## 13. 发布前检查

```text
[ ] 已声明主目标：收藏 / 评论 / 转化
[ ] 首图一眼可识别设计类别
[ ] 标题、首图和正文语义一致
[ ] 收藏型有明确可带走内容
[ ] 评论型有具体判断和两份证据
[ ] 评论问题足够窄
[ ] 转化型有真实经营问题与设计取舍
[ ] 没有用模板钩子替代证据
[ ] 文案没有压过作品
[ ] 没有把灵感合集伪装成完整原创案例
[ ] 已说明证据等级
[ ] 已记录主要搜索词
```

任一主目标的必要条件缺失，不得标记 `READY_TO_POST`。
