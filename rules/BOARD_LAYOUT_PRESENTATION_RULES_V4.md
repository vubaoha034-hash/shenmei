# 品牌案例整版展示与多模块排版规则 V4.2

版本：`4.2.0`
状态：`MANDATORY`

## 1. 目标

每张输出都必须像一页成熟餐饮品牌案例，而不是孤立效果图、零散素材集合、电商详情页或模板化提案页。

整套十张必须同时具备：

- 统一品牌语言；
- 不同页面角色；
- 明确主次；
- 克制文字；
- 配角跨页去重；
- 色温、明度和背景节奏；
- 可单独发布的完整性。

## 2. 默认画布

```text
比例：3:2 横版
推荐尺寸：2400 × 1600 px
格式：PNG
```

用户指定尺寸时以用户要求为准。同一套十张必须统一比例、像素、安全边距和品牌字标。

参考图若为多张横版页面上下拼接形成的竖长截图，不得把截图整体比例误判为单页比例。

## 3. 页面主次

每页必须明确：

1. 一个第一视觉中心；
2. 一个第二阅读区域；
3. 0—3 个辅助模块；
4. 少量必要文字。

推荐面积关系：

- 第一视觉中心：约 `55%—75%`；
- 辅助模块合计：约 `15%—35%`；
- 留白与文字：剩余空间。

Logo、主标题、食物和空间不能同时争夺最大面积与最高对比。

## 4. 模块数量

默认每页使用：

- 1 个主模块；
- 0—3 个辅助模块；
- 总模块数量通常为 1—4 个。

只有品牌元素页、海报系统页和运营触点页可在必要时增加模块，但必须保持清晰主次。

禁止用大量等尺寸小格子平均分配注意力。

## 5. 允许的版式骨架

### A. 满版主视觉

一个空间、产品或情绪场景占据主要画面，辅以极少字标和短句。

### B. 左大右小

左侧或右侧为绝对主视觉，另一侧放 1—3 个辅助模块。

### C. 上大下少

上方主图，下方 2—3 个细节或产品证据。

### D. 系统分区

适合字标、色彩、超级符号和必要标签。分区清楚，但不靠大量编号和微型英文制造专业感。

### E. 系列陈列

适合 3—4 张海报或产品系列。统一边距和节奏，但每个单元不能拥挤。

### F. 单体静物主导

适合包装系统。以一组完整静物为中心，辅以少量结构细节。

### G. 满版背景＋小型信息层

适合品牌故事或总结。背景承担情绪，文字只做必要补充。

### H. 深底高对比

使用深灰、炭黑、深品牌色或低明度背景，让食品、产品或白色字标成为主角。不得用纯黑加金字冒充高级。

### I. 冷静系统页

使用冷白、灰白、雾蓝灰、矿物灰或浅灰绿背景，以清楚网格、低饱和图形和准确对比建立理性气质。

十张至少使用四种不同骨架，并至少出现三种视觉状态：

- 图像满版或高占比；
- 大面积留白；
- 系统或系列陈列；
- 深色或强对比状态。

若品牌明确不适合深色状态，必须在 manifest 中记录替代方案与理由。

## 6. 配角物料跨页去重

### 6.1 允许适度跨页出现的品牌主角

- 定制主字标；
- 核心超级符号；
- 主产品；
- 核心空间气质。

即使是主角，也不得机械复用同一张图、同一裁切和相同比例。

### 6.2 原则上只重点出现一次的配角

- 手提袋、打包盒、杯、碗、餐具包；
- 围裙、员工服；
- 菜单牌、桌牌、取餐牌；
- 小票、会员卡、吊牌、贴纸、封签；
- 其他运营应用物料。

包装页完整展示包装后，应用页、产品页和总结页不得再次把同一包装作为主要模块。

应用页完整展示围裙、菜单、小票和会员卡后，总结页不得再次把这些物料缩小排列。

## 7. 文字密度

全套十张：

- 中等文字密度页面最多 2 张；
- 低文字密度页面至少 8 张；
- 正文段落原则上只允许出现在品牌故事页；
- 品牌元素页允许标签和短说明，但不得长篇解释；
- 其余页面只保留标题、品牌名、短句和必要标注。

页面不能因为有留白就补满文字、英文、图标、横线和编号。

## 8. 禁止序列号

最终页面中禁止出现：

- `01`、`02`、`03` 等页码；
- PAGE 01、SECTION 02；
- 角落大号数字；
- 章节序列号；
- 用编号制造提案感。

顺序只在 `CASE_MANIFEST.json` 中记录。

## 9. 色彩与背景策略｜V4.2 核心

### 9.1 暖色不是默认答案

不得因为品牌涉及手作、面包、粥、木头、家常或自然，就自动使用：

- 暖米色底；
- 奶油色纸张；
- 金黄日光；
- 木棕空间；
- 暖棕字体；
- 金色强调。

暖色只能是有品牌依据的局部选择。

### 9.2 背景家族

十张至少使用三类背景家族，可从以下选择：

- 冷白；
- 灰白；
- 雾蓝灰；
- 浅灰绿；
- 矿物灰；
- 深灰；
- 炭黑；
- 中性纸白；
- 品牌色实底；
- 局部暖底。

同一套中，任何单一背景家族不得占据超过 50%，除非用户明确要求统一特殊媒介，并在 manifest 记录理由。

### 9.3 默认数量限制

除非有明确品牌证据：

- 暖米、奶油、黄棕纸张底不得超过 3 张；
- 至少 4 张不得使用暖米或奶油底；
- 至少 2 张使用冷色或中性底；
- 至少 1 张使用深色、低明度或强对比背景；
- 不得连续 3 张使用相同背景家族；
- 不得连续 3 张使用相同色温。

### 9.4 单页四层对比

逐页检查四层：

1. 主图色温；
2. 背景色温；
3. 文字色温；
4. 强调色温。

四层不得全部同时偏暖。

至少一层必须承担冷、中性或深色对比。

### 9.5 正确组合

- 暖食物 + 冷灰背景 + 深绿字；
- 冷白背景 + 中性产品图 + 柿红局部强调；
- 深灰背景 + 白字 + 暖食物主角；
- 浅灰绿背景 + 中性空间图 + 黑色标题；
- 矿物灰背景 + 银白器皿 + 局部品牌色。

### 9.6 错误组合

- 金黄食物 + 奶油底 + 暖棕字 + 金色装饰；
- 暖木空间 + 米白纸纹 + 黄光 + 棕色 Logo；
- 十张都使用日落光、麦色纸张和暖木色；
- 仅降低饱和度，却仍然让所有页面保持黄、棕、奶油色温；
- 用统一暖色滤镜掩盖不同素材的质量差异。

## 10. 留白与边界

- 页面四周保持稳定安全边距；
- 模块之间保持明确间距；
- 留白服务第一视觉中心；
- 不用密集细线、页脚和微型英文填满空白；
- 不强制每页都有底栏、页眉或同一纸张背景；
- 冷色与深色页面同样需要留白，不得靠满版暗色压迫画面。

## 11. 图片裁切

- 食物主体不得切断关键结构；
- 门头字标必须完整可读；
- 包装模型不得切掉关键折角、提手或开口；
- 人物或员工服不得出现错误肢体；
- 空间裁切必须保留尺度和动线判断；
- 同页多图裁切应形成节奏，而不是随机尺寸。

## 12. 材质、光影与色温

同一页不同模块必须共享相近的：

- 色温逻辑；
- 对比度；
- 材质真实度；
- 商业摄影逻辑；
- 颗粒与锐度；
- 黑位和高光控制。

“共享相近色温逻辑”不等于全部调成暖色。冷、中性或深色页面同样需要内部统一。

禁止一张像棚拍、一张像手机快照、一张像塑料 3D 渲染而没有统一处理。

## 13. 跨页视觉节奏

十张不能全部使用：

- 同一米白纸纹；
- 同一标题位置；
- 同一左文右图结构；
- 同一底部图标栏；
- 同一模块比例；
- 同一暖黄光；
- 同一木色和奶油色。

统一应来自：

- 字标；
- 品牌主色；
- 材质逻辑；
- 摄影气质；
- 图形语言；
- 留白尺度。

差异应来自：

- 第一视觉中心；
- 图片占比；
- 背景家族；
- 色温与明度；
- 模块数量；
- 文字密度；
- 页面角色。

## 14. 参考图使用边界

可以参考：

- 横版案例页比例；
- 多模块组织；
- 信息密度；
- 图文主次；
- 品牌案例叙事顺序；
- 冷暖、深浅和背景切换机制。

不得复制：

- 品牌名称；
- 字标造型；
- 超级符号；
- 设计公司名称；
- 水印、联系方式、二维码和页脚；
- 完整页面壳与可识别商业外观。

目标是学习展示机制，不是复刻参考项目。

## 15. 禁止事项

- 一页塞入所有品牌内容；
- 多张图无主次随意拼接；
- 使用模板化“标题＋英文副标题＋三枚圆形图标”；
- 用大量小字、细线和编号冒充设计提案；
- 每页都把 Logo 放在正中间或最大位置；
- 每页都有大段说明文字；
- 配角物料跨页重复；
- 十张复制同一模板；
- 十张全部使用暖米、奶油或黄棕背景；
- 多数页面同时使用暖图、暖底、暖字和暖强调；
- 一张总览合板作为最终交付。

## 16. 页面通过标准

一张展示页只有同时满足以下条件才通过：

- 主题明确；
- 第一视觉中心明确；
- 模块数量克制；
- 文字密度符合页面角色；
- 没有可见序列号；
- 图像材质统一；
- 品牌字标一致；
- 未重复其他页面已经完整展示的配角物料；
- 背景与色温符合 `temperature_map`；
- 主图、背景、文字和强调色没有全部同时偏暖；
- 独立查看时成立；
- 与其他九页属于同一品牌，但不是同一模板复制。
