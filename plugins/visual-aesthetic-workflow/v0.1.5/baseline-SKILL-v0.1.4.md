This is an experimental thin workflow wrapper, version 0.1.4. The authoritative repository is `vubaoha034-hash/shenmei`, branch `visual-program-distillation-v2-photography-design-20260814`. Its current native lock, checkpoint, adapter, charter, freezes and review carrier control the native task. This plugin does not create a task registry or replace production skills.

1. Call `get_current_workflow`. Use its actual latest commit and bound current entry; stop if native hashes, mirrors or mainline verification fail. Historical actions in the entry do not override `next_required_action`.
2. For the existing native task, retrieve the bound reference and current delivered artwork original bytes with connected Drive tools, recompute SHA256 and view pixels. Its typography-only scope, paused photography and source protection remain unchanged. For a new user-uploaded reference, use the actual attachment, Drive ID or URL in this request, retrieve its original bytes and view its pixels. Until those checks occur, its SHA can be unknown and its visuals are unverified. A plugin response or image URL does not supply pixel evidence.
3. Route new user requests expressing “不改变结构 / 只改文字 / 保留原图 / 严格参考原结构” to `operation_mode:"structure_locked_edit"`; use `creative_transfer` for creative reference transfer. Include the user's exact intent in `user_intent`. In structure lock mode, a locator alone is insufficient: require the actual original image attached in this current context, readable and actually viewed. STOP if unavailable; never reconstruct it from text. Bind context ID, attachment ID, original-byte SHA256, actual decoded width/height and the actual image-tool edit target in `current_reference_binding`; never invent these fields or set flags before doing the reads. This remote plugin cannot see attachments and marks binding as caller-attested, not server-verified.

   Call `compile_transfer_plan` with the expected commit. `reference_scope:"native_task"` is the default and requires the exact bound native `reference_sha256`. For a new user reference, select `reference_scope:"user_request"` and supply bounded `reference_source` plus explicit `new_copy`; omit `reference_sha256` when unknown, or supply a canonical 64-hex caller hash that remains unverified until actual byte retrieval. This mode returns a request draft with `NOT_PERFORMED` verification and preserved `native_context`; it never rebinds the native reference. Its seven axes wait for this new reference's actual pixels, without inheriting native color, geometry or dimensions. Both modes use canvas, attention geometry, image anchor, material treatment, typography behavior, color logic and variation axis. Keep correctness separate from taste and reuse mature tools without rewriting upstream generation rules.
4. For `structure_locked_edit`, declare `editable_regions` with the original-pixel integer bounds, region-sized nonempty binary L mask locator and its actual SHA256. Only top text, main title (including its core English), right vertical text, footer short copy and minimal cleanup inside a parent text region are allowed. View and verify masks against the original before executing; an arbitrary rectangular region does not prove text-only scope. Missing dimensions or masks means STOP. Never inherit a guide's dimensions or resize masks.

   Obey `execution_contract`, `blocked_until` and `hard_preserve`. A BLOCKED/STOP response prohibits any image call. Immediately before editing, the actual carrier rechecks current context, attachment, viewed pixels, original bytes hash and the exact target consumed by the editor; use `execution-gate.mjs` when the carrier supports code. Use the original image as the image tool's explicit reference input. With local paths use `referenced_image_paths:[the_actual_bound_path]`; otherwise require the actual current attached image through the image tool's current-image input. Never call the image tool with only text. Edit only required local glyph strokes; preserve the original photo, subjects/people, crop, canvas, image/title/top/right/footer regions, whitespace, colors and existing decorations. No new maps, routes, place names, icons, people or decorations. Editor failure means STOP, with no text-to-image fallback. All generative material is GUIDE_ONLY, including whole-canvas edit output. Never deliver it as final. Finalize with `scripts/exact_composite.py compose` from the frozen original RGB/RGBA samples, region-sized RGBA local glyph/texture candidates and verified binary masks. This script requires --reference, --plan, --patches, --output (PNG), --provenance and --report. Do not resize, recrop, transform colors or JPEG-encode the final. Use Figma/Patchy only if their exported samples pass the same validator; otherwise use the supplied Python/Pillow finalizer. If deterministic composition is unavailable STOP: DETERMINISTIC_COMPOSITE_REQUIRED.

   Reopen the actual saved final with `scripts/exact_composite.py validate --reference ... --plan ... --candidate ... --provenance ... --report ...`. Require exact original width and height, exact aspect ratio and zero outside-mask changed pixels. Encoding/color management is not a reason to relax this. Original JPEG file bytes differ from PNG encoding; preservation concerns its decoded original RGB/RGBA samples, directly copied without another transform. The script reports engineering pass separately from semantic review. View original and final pixels for photo/two people/cabin/sunset/water/crop/layout and the exact new copy; bind observed review evidence to both file hashes. No script result or caller assertion alone proves an independent visual PASS or changes native acceptance.

   An edit contract or successful call is not pixel PASS: compare actual original and result for photograph, two people, cabin, sunset, water, original crop and overall layout. Report FAIL when changed; report BLOCKED when no real result exists.

   A draft does not grant quota. The actual execution carrier checks applicable scope and existing user authorization before production; authorization already covering the request remains usable, so do not demand repeated approval solely because `execution_authorized:false` appears in this draft. Use the actual image tool within that scope and connected Figma tools when editable source is part of delivery. Record actual calls, failures, source identities and exposed settings; a draft is not generated artwork or an accepted result.
5. Send actual reference and newly created artwork original pixels through the existing independent review carrier without creator history or human verdicts. For `user_request`, its packet contains only this request's reference, exact new copy and newly created artwork; exclude `native_context`, old artwork, old feedback, scores and verdicts. Preserve actual image-byte transport, model, runtime and isolation evidence. The plugin cannot instantiate an independent reviewer. If the route or pixels are unavailable, stop at `NEEDS_INDEPENDENT_PIXEL_REVIEW`; self-review and code tests cannot promote the work. AI review never replaces Liu's acceptance.
6. Repair only within applicable existing authorization and actual observed evidence. Save original artwork and editable source to authorized destinations and verify readbacks. For the native task, only the existing Root writer updates and publishes the same native state; when its next action is human review, do not start another native formal version. A user-request draft leaves that lock, checkpoint, adapter, ledger and next action intact.
7. For an explicit human rating of the current native delivery, call the published `save_human_feedback` tool with expected commit, exact delivered artwork SHA, a stable idempotency key, `APPROVE`/`REJECT`/`COMMENT`, and the user's comment. Its binding remains the native delivered artwork; a new request draft does not change that binding. Require `persisted:true` and its durable receipt, then verify it with `get_human_feedback`. The core-only `prepare_human_feedback` validates an intake but does not save it and is not a published workflow tool. Root reconciles this append-only **non-authoritative intake** with the native authority. Neither a feedback record nor an AI score may automatically change mainline, AI verdict or human `PENDING`.

Recognized and rejected outcomes remain scoped evidence. One rating defaults to observation; do not blindly append visual rules or claim universal transfer, improved efficiency or training. This wrapper initiates no training, scheduled runs or paid compute. Capability and adapter details are in [README.md](README.md).
