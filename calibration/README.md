# 私人审美校准

AI 不能自动知道“刘先生喜欢什么”。私人审美必须通过明确样本校准，不能从年龄、职业、地区或历史常识猜测。

## 目录建议

```text
calibration/
├── anchors.json
├── approved/       明确喜欢、愿意作为正向参考的图片
├── neutral/        觉得一般、可用但不满意的图片
├── rejected/       明确不喜欢的图片
└── references/     顶级行业参考，不一定等于私人喜欢
```

Git 不保存空目录。上传图片时再建立对应文件夹即可。

## 每个锚点必须记录

- 唯一 `id`
- 作品类别
- 文件路径或稳定 URL
- 用户明确标签：`approved` / `neutral` / `rejected` / `reference`
- 用户给出的总分或分数区间（可选）
- 喜欢或不喜欢的具体原因
- 确认日期
- 是否仍有效

## 锚点最低要求

- 少于 3 个同类别有效锚点：不得评分 `personal_fit`；
- 3–7 个：只能作为低到中等置信度参考；
- 8 个以上，且至少包含 2 个 approved、2 个 neutral、2 个 rejected：可以正式计入；
- 顶级行业参考图与私人喜欢必须分开，不能混为一谈。

## 如何避免 AI 迎合

1. 用户先独立标记喜欢/一般/不喜欢，AI 后看原因；
2. 新图先匿名成 A/B/C，再与锚点做成对比较；
3. AI 必须说明“更接近哪个锚点，具体接近在哪里”；
4. 不能因为用户刚刚夸过某张图就自动提高同类图片分数；
5. 锚点发生冲突时，优先使用更新日期更近、理由更具体的样本；
6. 每次修改评分标准必须提升 `rubric_version`，旧结果不得静默重算。

## 建议的首次校准

每个类别准备 12 张：

- 4 张非常喜欢；
- 4 张一般；
- 4 张明确不喜欢。

不要只放顶级作品，否则系统只能学会“什么最好”，无法学会你的边界和雷区。

## 锚点更新

当用户明确说“这张我很喜欢”“这种修图很假”“以后不要这种”时，才新增或更新锚点。AI 的推断不能直接写入私人锚点库。
