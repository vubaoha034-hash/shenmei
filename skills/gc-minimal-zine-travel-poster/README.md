# GC Minimal Zine Travel Poster v1

仓库内调用名：`gc-minimal-zine-travel-poster-v1`

这是基于 `LiamGvchi/gc-minimal-zine-poster` 的 16:9 旅行影像改版。

## 相比原版的主要变化

- 画幅从原版默认 3:5 竖版改为 **16:9 横版**；
- 不再固定“极小主体 + 70%-90% 留白”，旅行照片模式允许主体/地形占更大面积，以保留地点辨识度；
- 每次从多种视觉语法中选择：撕纸照片、色块场域、地形/等高线意象、窄幅照片切片、标本式主体、分层地貌、文字主导；
- 色块、贴纸、意象不是叠加装饰，而要从原图中的天空、山体、湖面、建筑、人物服装等视觉锚点生长出来；
- 已知地点时，在留白区域加入准确的英文/罗马字地名；未知地点不得瞎猜；
- 禁止为了“专业感”编造坐标、日期、档案号、机构名或无意义英文；
- 增强参考照片保真规则，优先保留地形轮廓、建筑形态、人物姿态和空间关系。

## 示例调用

```text
用 $gc-minimal-zine-travel-poster-v1 把这张旅行照片做成 16:9 的复古 ZINE 海报。
地点：羊卓雍措，西藏，中国。
保持湖岸和山体轮廓，不要变成商业旅游广告。
```

```text
用 $gc-minimal-zine-travel-poster-v1 处理这张照片。
这次不要撕纸照片方案，随机从色块场域、地形意象、窄幅记忆切片里选一种。
```
