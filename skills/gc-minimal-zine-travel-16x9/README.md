# gc-minimal-zine-travel-16x9

旅行视频 / 照片 Zine 转换 Skill。

> 注意：Skill 名保留 `16x9` 只是为了兼容现有调用，**16:9 已不再是默认画幅**。

## 调用

```text
用 $gc-minimal-zine-travel-16x9 按这张参考图的感觉处理这张旅行照片，地点是福建渔山岛。
```

如果明确需要 16:9：

```text
用 $gc-minimal-zine-travel-16x9 处理这张旅行照片，按参考图的视觉逻辑，但最终画幅改成 16:9。
```

批量视频帧：

```text
用 $gc-minimal-zine-travel-16x9 处理这一组旅行视频帧。画幅优先按参考图；保持纸张和字体系统统一，但每张在贴纸、色块拼贴、景观版画、等高线、建筑解构或意象剪影之间做受控变化，不要连续重复同一种构图。
```

## 画幅优先级

1. 用户明确指定的比例或像素尺寸；
2. 参考图中真正的设计画面比例；
3. 没有可用参考比例时，保持原照片 / 视频帧比例。

社交平台截图的手机外框、黑边、播放器、上下对比区域不参与比例判断。

## 默认输出逻辑

- **不强制 16:9；**
- 优先按参考图的比例、方向、留白比例和主体尺度；
- 没有明确参考比例时保持源图比例；
- 只有用户明确要求时才主动转换成 16:9；
- 使用旧纸 / 扫描 / 丝网 / 半调等印刷质感，但以参考图为准；
- 保留原始场景关键几何与人物关系；
- 根据原图提取有意义的主强调色；
- 已知地点且参考构图允许时，在留白处加入英文地名；
- 不生成手机界面、抖音 UI、播放器控件或上下对比截图；
- 不虚构坐标、天气、日期等事实信息。

详细规则见 `SKILL.md`。
