# gc-minimal-zine-travel-16x9

旅行视频 / 照片横版 Zine 转换 Skill。

## 调用

```text
用 $gc-minimal-zine-travel-16x9 处理这张旅行照片，地点是福建渔山岛。
```

批量视频帧：

```text
用 $gc-minimal-zine-travel-16x9 处理这一组旅行视频帧。保持纸张和字体系统统一，但每张随机轮换贴纸、色块拼贴、景观版画、等高线、建筑解构或意象剪影；不要连续重复同一种构图。
```

## 默认输出

- 16:9 横版；
- 旧纸 / 扫描 / 丝网或半调印刷质感；
- 保留原始场景关键几何与人物关系；
- 根据原图提取一个主强调色；
- 已知地点时，在留白处加入英文地名；
- 不生成手机界面、抖音 UI、播放器控件或上下对比截图；
- 不虚构坐标、天气、日期等事实信息。

详细规则见 `SKILL.md`。
