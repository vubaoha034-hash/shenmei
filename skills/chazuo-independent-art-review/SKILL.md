# Independent art review

Read the current native lock and latest correction before preparing a packet. Only the executor reads project state; the reviewer receives an isolated brief and actual images, with target human verdict and earlier AI conclusions hidden.

Use the pinned, minimally packaged [design-critique](../design-critique/SKILL.md). Its official upstream is preserved byte-for-byte in `../design-critique/upstream/SKILL.md`, Apache-2.0. For a static poster, navigation, touch targets and interaction accessibility are inapplicable. Keep its first impression, hierarchy, consistency, visible evidence and priority recommendation workflow. Changing Markdown to native JSON is an output adapter, not a new aesthetic scoring system.

Reuse `personal-aesthetic-critic`'s permitted quick diagnosis: inspect pixels first, distinguish photography/design/brief compliance, anonymize the target, avoid private preference scores without sufficient anchors. This is qualitative AI review, not an OFFICIAL numerical score or a human expert credential.

Prepare P/N/R/S/T as defined by `SKILL_REVIEW_CARRIER_AMENDMENT.json`: P has approved typography/layout but rejected photography; N is a rejected design; R is the original upper-ad reference; S is the correctly identified first photograph with rejected typography; T is the blind current poster. Do not turn partial approval into whole-image approval.

Give a new `fork_turns="none"` reviewer the task requirements, inline skill workflow and five exact image paths only. It may use `view_image` only, once per image. No repository, source code, session, author rationale, prior review or creator self-score is supplied. The observer compares wordmark structure, reading hierarchy, image/text relation and visible completion, giving at most three priority corrections with region-specific evidence. Technical source preservation or editable layers cannot be proved by visual inspection alone.

Save the actual finished reply using `scripts/vpd_collect_agent_review.py --supplemental-source --carrier-amendment continuity/vpd/codex_takeover_20261003/SKILL_REVIEW_CARRIER_AMENDMENT.json`. Audit the actual spawn, model/Max, five ImageView events and absence of other tool reads. A fallback model requires `--expected-model` and `--capacity-failure-receipt`, preserving an actual PIXEL_REVIEW capacity failure; a research-role failure cannot substitute. Failure to see images or verify isolation means unable to evaluate. Preserve the original four-image production protocol and historical results.

The root executor binds the supplemental report to the existing native receipt, checkpoint and ledger. It continues the current unique next action; this skill never increases the version budget.
