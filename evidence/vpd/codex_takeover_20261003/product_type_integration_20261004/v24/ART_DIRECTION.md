## 唯一方案：六个制作变量

下列坐标均为 1536×1024 全画布坐标、左上原点；是这一版的制作目标，不是审美通过阈值。采用温白，直接采样现有主句填色，透明底。

1. **轻而有骨的字形。** 制作一份新的透明主句字层，准确为“一杯茶，慢下来”。仍保留手写的提按，但改为直立、较窄、开口明确的骨架；主要竖笔目标宽 8—11 px，横笔 4—6 px，撇捺中段 7—10 px、末端 2—3 px。去掉旧字群的圆团起笔和每笔同粗；端头采用短斜切，不统一加圆角，不加飞白颗粒、额外长飘带或装饰叶。数字只规定可见轻重，不作 validator。
2. **逐字比例。** 原17路径只作文字身份/结构对照，不能作为最终整体缩移结果。目标墨迹框：一 `[612,526,700,539]`；杯 `[712,431,839,608]`；茶 `[858,419,1008,525]`；逗号 `[1023,541,1038,569]`；慢 `[851,539,968,646]`；下 `[1011,572,1094,681]`；来 `[1116,554,1235,681]`。新主句总体约 `[612,419,1235,681]`，623×262。杯高、茶较展开、慢略紧、下窄、来舒展；保留汉字部件和正确笔画，不用六个等大的方格。
3. **字间与行脚。** 第一行“一杯茶，”在上，第二行“慢下来”向右推进；一位于杯的中下段高度，不能将短横垂直居中于整句大框。第二行左脚慢停在 y=646，下来落至 y=681，形成向盘右下侧展开的斜向脚线。慢—下之间约43 px的墨迹间隙用于容纳真实叶尖方向，下—来约22 px；不要把两行等间距排齐，也不要让逗号变成孤立大白点。
4. **杯口进入字骨。** 杯的木旁竖笔主要骨架沿 x≈742，从 y≈451下行，最后约35 px向杯口右外侧轻收，终点约 `(759,605)`；这是笔画轮廓编辑，不另加弧线。木旁左撇收于约 `(700,541)`，在杯口上方停笔；右侧“不”的撇捺不横扫杯面。字的底端与杯口右端形成相邻轮廓，杯沿连续亮边保留。竖笔不能为了躲杯被硬切成悬空半截，应先改骨架，再对极小残余碰撞做透明差集。
5. **让真实叶簇成为字间空隙。** 慢的忄保留较长竖笔，曼部压实在上方；其最下“又”的右捺提前向右上收，终点约 `(950,610)`，而不是延伸压在叶脉上。下的长横从 `(1011,577)` 起，竖笔在 x≈1052，下至 y≈679；真实上扬叶尖留在慢—下的开口内。茶的木部右捺沿轻微右上趋势收在 `(1005,518)`，呼应叶片方向但不画成叶子。叶尖、叶脉和前叶片边缘从摄影层自然露出；不替换任何汉字必需笔画，不把叶片当作偏旁。
6. **合成与留白。** 图层顺序：原字节摄影 S → V9茶作七路径（仍 x=285、y=198、宽205）→新主句封闭路径。只采用 source-over。允许在主句路径上做透明负形；不盖照片、不补照片核心、不提取叶子再贴回、不用隐藏照片层、clipPath、mask、滤镜或描边绕物。摄影色彩、材质、构图、光影均不动。

## 透明负形怎样可复算

以下两条封闭 Bézier 路径是**字层的排除包络**，不是声称已完成精确抠图。故意略放松于物体边缘，形成数像素空气，且只从字层减去；不会修改任何摄影像素。主执行者应优先按上面的骨架避让，包络只清除最后残余相交。

杯包络 `CUP_AIR`：

```text
M 318 590 C 329 563 437 542 542 545 C 650 544 743 561 757 587 C 765 611 734 633 714 668 C 690 729 668 797 625 822 C 563 845 448 829 405 787 C 365 743 341 659 318 590 Z
```

叶簇包络 `LEAF_AIR`：

```text
M 806 660 C 836 638 845 611 870 586 C 884 610 876 630 871 640 C 921 626 970 600 1008 565 C 1006 604 976 635 950 652 C 974 683 988 726 996 765 C 944 744 902 717 875 705 C 844 692 821 678 806 660 Z
```

将新字符各笔画定义为闭合填充轮廓 `G_i`，在制作源码中求 `F_i = G_i − union(CUP_AIR, LEAF_AIR)`，再把结果写成仅含 svg/g/path 的普通复合路径。曲线布尔运算可用现有可靠几何工具；若需展平，统一弦误差0.25 px，保存输入路径、参数与输出，不把二值照片分割用于这个步骤。这里的0.25仅是几何复算精度，不是审美阈值。不要输出绘制用白色/深色遮罩路径。孔洞和方向必须在输出中显式成立；描摹后的负形应显示摄影原层。

如包络吃掉“杯”木竖或“慢”曼部的识别关键，返回上述单字骨架移动局部节点、控制柄或收笔，随后重算差集；不通过回贴照片、硬删整笔或整体搬移句群解决。给定字框与包络尚未渲染验证，制作时以正确字形和可见产品边缘为约束完成这一份资产，不能把本报告当作像素证明。
