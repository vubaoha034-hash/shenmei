## 给下一版制作者的两项小范围建议

1. **先识读，再处理局部笔画与负空间。** 对 Root 本轮唯一确定的文案和唯一字形源，在实际显示大小下逐对检查字间空隙和字内密集部件。先保留识读必要笔画，再改必要的收笔与间隙，形成一个字群。此方法来自 Martin_K 的实际可见教学文字；M 的三个主标虽不规则仍读成一个共同体，是本次适用性推断。不要把每个字随意缩放，也不需要把拖尾贴到杯沿或叶片上。冻结的茶作字标轮廓和摄影源继续保留。

2. **按角色分配可见重量。** M 值得学的是粗短主标、细小表达句、小号说明各司其职。以现有茶作品牌角色为锚，本轮被允许的短文案承担第二层，与品牌共用一条对齐线并形成紧凑信息组。作为一次试做起点，第二层可见字高先取品牌可见字高约三分之一至五分之二，随后看完整海报与缩略图，确认品牌、文案、杯与盘的读序。这里的比例是目视起点，未测量为山野集精确参数，不加入 validator。不要重现 V28 前半句巨大、后半句显著变小的两套重量。此项主要来自 M/S/T 原件观察，抖音智能文稿只提供有限佐证，不能归功于未观看的视频。

需要保留的是自然书写气质、冻结摄影、已改善的茶作品牌资产和一个当前方向；需要修正的是把“自然”等同于整句同重书法、长拖尾或强行触碰产品轮廓。山野集不是山葵炙；M 的山形、橙圈、署名与商业外观均不能拿来充当茶作原创。
